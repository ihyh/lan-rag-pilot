# 人工核对题的隔离复测

用途：重放人工确认的完整独立问题，保留限定文档范围和资料身份；不是自动判断整答正确的评分器。

## 准备

1. 准备此前人工核对并保留的 `rag-eval-v2` JSONL；当前管理页不提供反馈导出。
2. 准备独立服务和数据库副本，使用非生产端口（例如19242）。副本须保留原文档ID、chunk ID、原始SHA、版本、索引正文及位置；重新导入/改ID不能静默映射。
3. 禁止指向个人生产服务8088或Tailscale生产入口。工具只接受明确指定的本机回环地址、非8088端口，且不跟随重定向。显式声明隔离只是操作确认，程序不能证明任意端口背后真的不是生产；操作人仍须核对进程/DB配置。

默认只校验文件，不登录、不发题；查看 `python scripts/isolated_replay.py --help`。执行还必须显式提供 `--execute`、`--isolated`、隔离服务地址和新报告路径。使用隔离库的root账号；不要把密码、私有导出文件或报告提交到GitHub。

```powershell
# 仅校验；将路径替换为此前保留的私有题目文件
python scripts/isolated_replay.py --cases D:/rag-tests/verified.jsonl
# 先人工确认19251确为隔离库，并准备密码环境变量；报告目录须已存在
python scripts/isolated_replay.py --cases D:/rag-tests/verified.jsonl --execute --isolated --base-url http://127.0.0.1:19251 --username root --password-env RAG_TEST_PASSWORD --out D:/rag-tests/replay-new.json
```

## 执行和结果

每题执行前后核对 `/api/admin/eval-manifest` 的5项身份：文档ID、文件名、原文件SHA、版本、索引SHA。缺少/变化立即停止该题，不回退全库，不借用既有对话。问题请求带确切文档ID，返回范围不一致按执行失败记录。

报告保留新答案、原答案/审核参考、实际请求范围与执行状态；旧题文件和旧报告不能覆盖。即使请求成功，`whole_answer_supported` 仍为空且 `manual_review_required=true`。关键词/引用格式检查至多作为 `heuristic_pass`，不能当整答通过。

日志正确来源使用完整的 `line_start` / `line_end` 闭区间，`page` / `paragraph` 必须为空；缺端点、倒序、非整数或混用页段坐标均拒绝。页码/段落资料沿用原契约。来源身份相同但日志行号不同，不能算引用位置命中。

直接入库的图片人工说明不伪造页码：人工选中的说明片段以图片原件 SHA、片段 ID 和片段正文 SHA 标识，并由审核流程写入 `location_kind=image_caption`。导出及隔离重放前后核对原件、资料标签、片段和范围身份；该定位只能证明使用了对应的人工说明，不能证明说明与原图一致或答案正确。旧题格式不受影响。

人工选源界面显示真实日志行号，保存审核时由服务端从索引取坐标，客户端不能提交坐标替代原值。冻结范围摘要对日志绑定元数据和行位置，变化后旧确认失效；普通文档保留原摘要算法，旧题不会仅因新增日志支持而全部失效。检查的是索引身份/物理行数一致性，不重新识别原件，也不能证明答案含义正确。

按 [整答验收判据](./_history/ANSWER_ACCEPTANCE.md) 人工逐条核对核心事实、来源支持、无依据扩写、自相矛盾、错误事实和误拒答。不要把合成样本/工具回归成绩报告为真实业务正确率。

## 本轮边界

工具不重放多轮历史，不自动审核真实反馈，不更换模型/检索开关，不重建生产索引，也不向生产发题。先人工核对少量真实反馈和扫描件，再建立保留题；后续针对失败类别逐项优化检索/选段/生成。
