# 发布与验证边界

更新：2026-11-02。本页描述验证要求，不把过去某次部署的 PID、文件数或通过数当作当前结果。

发布应记录源码提交、配置及模型、资料备份和回退办法，检查登录、权限、文档导入、引用和历史持久化。数据备份与源码版本需要配套；代码同步不自动迁移或重建索引。

工程检查包含静态语法、合成检索/权限/反馈回归、前端 DOM 交互、mock HTTP 冒烟及重启持久化。记录失败、环境跳过和未测项；DOM 检查不能替代真实浏览器与移动端验证。

独立业务验收目前按用户要求暂跳过，不计通过。已有调试题和合成测试不能证明全库准确率。真实问题评测按 [业务评测流程](../eval/BUSINESS_EVAL_WORKFLOW.md) 执行，保留首次结果及人工证据。

旧部署记录见 [历史目录](_history/README.md)，不作为今日的待批准清单。当前能力见 [开发进度](../ROADMAP.md)。
