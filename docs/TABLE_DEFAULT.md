## 行为

- 问题同时问索引、默认值等属性时，分别回答可靠表头/目标行能支持的项目；不再静默漏掉默认值。
- 独立Default角色仅识别明确列标签：Default、Default Value、DefaultValue、默认/默认值及繁体对应写法。大小写/空白可归一化，输出保留真实列名、单元格字面和目标行+表头引用；不把数字转成浮点数。
- Default、裸Value、Current/Actual和Example彼此不代替。缺默认列、缺单元格或空值明确说明，不借其它列；文档默认值不能当作设备此刻设置值。
- 多个默认列在请求默认值时要求澄清；仅问可靠Index时仍可回答Index。不同文档同名记录有差异按来源分别列出，不判定标准。
- 文件/工作表和同文档表头绑定沿用原路径，不能跨范围借列。字段名含Default时，只复核新增默认属性意图，不改变既有Value/Current判断。
- 裸P号仍仅按Index数字导航，并说明P别名尚未证明；带小数、标识符后缀和文件名中的P不能取整数前缀。
