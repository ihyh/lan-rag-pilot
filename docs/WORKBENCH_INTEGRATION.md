# 客户端入口与严格离线范围

[返回首页](../README.md)

现行方案使用受管浏览器直接打开内网 HTTPS 地址。管理员可以分发浏览器书签或本地桌面快捷方式；入口仍使用 RAG 自身账号，不等于单点登录。

以前的企业微信/飞书工作台指南涉及外部平台及客户端依赖，不纳入本次“运行设备禁止互联网”的方案。旧步骤不再作为部署要求；本页不提供云平台接入、OAuth、回调或公网穿透教程。

即使某个云客户端能缓存一个内网链接，也不能据此认定它离线、安全或不会上传数据。若将来需要工作台入口，应由 IT 证明该入口及其客户端符合离线边界，另行评审，不放宽当前网络政策。

客户端验收：内网 DNS/证书受信任、登录和问答引用成功、非允许网段不可访问、无云同步/不受信任扩展。客户端不安装模型，不直接连接 Ollama。见 [首次使用](GETTING_STARTED.md)与[安全要求](SECURITY.md)。
