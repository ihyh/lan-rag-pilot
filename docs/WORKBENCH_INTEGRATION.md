# 企业微信 / 飞书工作台接入清单（HTTP 试点）

更新时间：2026-09-04

## 当前入口

```text
http://172.16.3.50:8088
```

这是当前局域网入口。企业微信和飞书只负责打开这个网页，RAG 仍使用自己的账号密码登录；本阶段不启用机器人、回调、OAuth 或统一登录。

## 企业微信

由企业微信管理员操作：

1. 打开[企业微信管理后台](https://work.weixin.qq.com/)。
2. 进入“应用管理”，创建一个“自建应用”。
3. 填写应用名称，例如“局域网知识库助手”，设置图标和可见范围。
4. 将“应用主页”设置为：

   ```text
   http://172.16.3.50:8088
   ```

5. 保存后，在企业微信“工作台”中打开应用。

## 飞书

由飞书管理员或应用管理员操作：

1. 打开[飞书开放平台](https://open.feishu.cn/)。
2. 创建“企业自建应用”，填写名称和图标。
3. 添加网页入口（不同租户可能显示为“网页应用”“应用主页”或“工作台入口”）。
4. 网页链接填写：

   ```text
   http://172.16.3.50:8088
   ```

5. 将可用范围设为试点团队，并发布/启用应用。
6. 在飞书工作台中打开应用。

## 验收

分别从企业微信和飞书客户端打开入口，确认：

- 能显示 RAG 登录页；
- `root` 或普通 `user` 可以登录；
- 能完成一次问答；
- 手机已连接公司 Wi-Fi 或 VPN；
- 电脑或手机不能访问公司局域网时，入口失效属于网络限制，不是 RAG 应用故障。

## 当前限制

- 这是 HTTP 内网试点，账号和会话存在被同一局域网窃听的风险。
- 部分企业微信/飞书租户可能禁止 HTTP 网页入口。如果后台拒绝保存或客户端提示必须 HTTPS，本清单无法绕过该限制，需要之后配置 HTTPS。
- 不要把 `DEEPSEEK_API_KEY`、`.env` 或数据库上传到企业微信、飞书应用后台。
- 两个平台都只配置同一个网页 URL，不要把 Ubuntu 地址 `192.168.136.128:8088` 暴露给员工。
