# Windows 个人服务安全边界

本项目定位为受控主机上的个人知识库。默认监听 `127.0.0.1`，远程访问使用同一 Tailscale 私有网络的 HTTPS Serve。不启用公网 Funnel，不开放路由器公网端口；也不应把管理账号密码交给不受信任的人。

## 配置与凭据

`.env`、私人文档、数据库、模型和本地评测证据不提交到仓库。使用独立强密码和随机 `RAG_SECRET_KEY`。`RAG_ROOT_PASSWORD` 只用于空数据库首次创建 root。使用实际 HTTPS 地址配置 `RAG_PUBLIC_ORIGIN` 和 `RAG_COOKIE_SECURE=1`。

启动校验拒绝缺失密钥、未受信任公网模型地址和不匹配的 Cookie/来源设置。`RAG_ALLOW_INSECURE_START` 仅供隔离调试，不是生产解决方案。本机模型请求默认不继承系统代理。

## 已有保护及限制

- 密码哈希、带签名会话、文档权限过滤、审计与反馈记录。
- 上传和解析预算、解析子进程及超时隔离；Windows 下不保证解析内存硬上限。
- 检索来源作为不可信数据；不执行文档中的指令，回答要求依据来源及引用。
- CEID 同 ID 场景分离、冲突提示与不完整定义提示；这些保护不是所有格式和问法均正确的保证。

不提供 MFA/SSO，不提供应用层静态数据加密或不可篡改审计。备份含敏感内容，应限制访问并单独加密保管。服务仅支持单 worker；不要把多进程部署当成提升吞吐的无风险设置。

模型仍可能犯错，工业规范结论必须核对原文和版本；不能据此直接控制设备。测试与重建使用独立目录和非生产端口，保留原始答案及失败证据。报告问题时去除私人文档、密码、会话令牌和用户信息。
