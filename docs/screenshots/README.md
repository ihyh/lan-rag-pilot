## 数据边界

全部账号和资料均为本次创建的演示数据；截图中的 root 是独立演示数据库的管理员，不是本地生产账号记录。`demo_editor`、`demo_reader` 及示例文档均为虚构。

问答使用模拟模型，仅展示回答布局和引用交互，不能用作真实设备操作指引或模型准确率证据。生产数据库、账号密码、会话、用户上传的文档及图文原件没有用于这些截图，也没有包含在本目录中。

演示服务的配置、密码、数据库、原始文件和日志留在本地忽略目录，不进入仓库。仓库仅保存这四张公开截图与说明。
