# 资料检查与答案纠错

系统管理员和文档管理员从顶部“查资料”，或文档列表“检查正文”进入。普通用户的问答引用仍受原有权限控制。

## 原文检索

输入关键词，明确选择单份资料或全部已就绪资料。空格分隔多个词时要求同时出现在同一片段；ASCII 英文字母不分大小写。结果显示文件、位置和匹配片段，可以打开原件核对。

检索只读索引正文，不调用生成模型，不跨片段拼接长句。历史版本需显式勾选；范围独立于聊天页，不修改已开始对话的资料范围。未找到匹配不代表原件没有答案，可缩短关键词或检查正文。

## 文档体检

选择资料后查看片段、位置、处理状态和失败原因，分页检查正文。表格、图片、OCR 数值和页码应对照原件；有索引文字不代表提取完整。

PDF 可显式核对原件页数。这只读取原件，不重新 OCR 或重建索引。无法解析时显示未知，不用数据库原有页数字段冒充物理页数，也不把含重叠的片段字符数当成全文完整率。

## 反馈闭环

回答下的“纠错 / 补充依据”保存用户补充，不改写原答案。root 在“资料管理 → 审计 → 用户反馈”核对问题、来源和处理结果。

已支持审核状态、可选分类、期望回答、处理说明、正确来源及可选复测信息；有帮助反馈无需审核。删除反馈不删除原问答和资料。管理页面不提供 CSV 或回归候选导出。

审核只是人工工作记录，不自动修正文档、训练模型或执行评测。完整约束见 [反馈审核](FEEDBACK_REVIEW.md)。
