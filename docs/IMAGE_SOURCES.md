# 图文资料与图片来源

在“资料管理 → 文档 → 图文资料”选择 PNG/JPEG 图片，按需标注设备，填写关联文字并核对后上传。说明应写清设备、接口、连接关系和数值；图中标注错误或不确定项应明确指出。

“AI 分析图片”用于辅助整理，依赖已配置的视觉模型。结果需对照原图核对；追加到说明后才作为人工填写内容使用，不自动训练模型或修改其它资料。

人工说明是检索依据之一，不证明图中文字、连线或判断正确。来源按原图与说明片段定位，不伪造 PDF 页码。扫描件和无说明图片的识别流程见 [OCR 上传](OCR_UPLOAD.md)。

旧网页图片保留兼容读取与来源提示；当前不提供网页图片批量采集入口，也不随仓库发布本机图片或旧批次报告。网页兼容边界见 [网页来源](WEB_IMPORT.md)。
