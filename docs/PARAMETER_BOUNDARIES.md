## 改动

- 同片段或不同来源出现同号Byte时，顺序保留每条定义、原来源编号和文件名，逐条附定义文本；提示核对设备、命令和版本，不选择“标准答案”。相同记录重复出现也不自动宣称冲突。
- `1.50`、`-4`、`0x28`、`1e-3`等按完整字面处理，不转浮点或截整数前缀。范围、分数、未知格式、多值和未解析续项不能总结成唯一数值；显示提取边界并保留定义文本。
- 同行多个Byte分开；空行和明确标题停止续段。仅合并括号内/开括号的可识别折行，闭括号后同行的新Byte另行归属。普通归属不明续行整分支返回`None`，交回既有生成路径。
- 请求的属性缺少时逐项说明“已识别的Byte定义中未明确提供”，不把整份文档说成没有。普通`Pulse count`不被改写成重试次数；显式否定单位不生成正向单位结论。
- 带文件样式名称的问题暂不由该分支接管，交回原检索范围/生成流程；没有新增自然语言文件、设备或协议范围解析器。手动选定文档范围继续由既有检索约束。

定义文本会合并已识别折行，不等于原件排版的逐字复制。需要完整输入上下文时仍以保存的来源片段和原件为准。
