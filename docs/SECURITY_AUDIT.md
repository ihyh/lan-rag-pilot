## 已确认的上线阻塞/风险

1. **文档 ACL 缺失：** 统一文档库对登录用户开放；部门/人员隔离需求尚未实现。必须实现并通过直接接口越权测试，才可用于要求隔离的企业部署。
2. **外联不是 fail-closed：** 模型地址缺失可回退公共 URL，离线变量不能阻止任意 socket。需要网络默认拒绝出口，显式本地地址，未来再补程序校验。
3. **密钥默认不安全：** SECRET 缺失回退固定开发密钥；启动只警告。发布验收必须检查非空随机值，不能依靠程序自动把关。
4. **旧部署示例暴露风险：** 基础 Compose 发布所有接口的 8088；HTTPS override 端口合并可能保留原映射。现行 Ubuntu 文档提供独立配置，仓库示例本身未在本次修改。
5. **文件/容器加固不足：** Dockerfile 未指定非 root 用户；没有完整恶意文件沙箱、病毒扫描或压缩膨胀限制保证。
6. **数据及审计：** SQLite/原文件没有应用层加密；备份、历史问答也含资料，审计不是独立不可篡改系统。
7. **单进程：** 进程内限流/并发/索引不支持直接多 worker 或多副本扩容。

优先级与后续验收见 [路线图](../ROADMAP.md)。这些结论描述已检查到的边界，不代表不存在其他问题。
