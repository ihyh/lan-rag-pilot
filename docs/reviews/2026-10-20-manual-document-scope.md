## API 契约变化

请求 `POST /api/query` 新增可选字段 `scope_mode`：

- `all`：全库检索。不得同时提供非空 `document_ids`（422）。
- `selected`：仅选中文档。新对话必须提供至少一个 `document_ids`（清空勾选传空数组 → 422，不再回退全库）；追问可只传 `conversation_id`（范围已固化在对话上）。
- 省略：兼容旧客户端，沿用「不传/空数组表示全库」的历史语义。

已有对话（带 `conversation_id`）：

- `document_ids` 与对话固化范围不一致 → 409（原有行为）。
- 显式 `scope_mode` 与对话固化模式不一致 → 409（新增）。
- 省略 `scope_mode` 的旧客户端追问仍允许。

响应回显（非流式与流式 `done` 事件、对话详情）：

- `scope_mode`：`all` / `selected`，按**实际生效**的范围计算。
- `document_ids`：实际生效的限定文档列表（全库为空数组）。
- 对话详情先按存储范围判定模式、再做可见性过滤，避免把「仅选中文档」显示成「全库检索」。

错误语义：

- `422`：零勾选 / 全库带文档 / 未知模式（Pydantic 校验）。
- `400`：所选文档已删除或未就绪（对可见该文档的账号，明确提示不重试旧选择）。
- `404`：对话不存在，或普通用户限定了对其不可见的文档（沿用「不暴露文档是否存在」的既有安全语义）。
- 持久化格式未变（仍为 `conversations.document_ids`），无数据库迁移。

5. 测试是否真实验证了「引用不越界」，而不是只看 DOM（`api_smoke.py::test_scope_modes` 先证明全库会召回范围外相似文档，再证明限定后排除）。
