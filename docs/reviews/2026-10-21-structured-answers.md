## 动机（来自真实问题定位与复核）

- H04：目标行 `A18=20；B18=Input Monitor Time；C18=/；...E18=单位ms` 已进入上下文，
  模型仍回答“索引为 18”（行号当索引），并把 Unit/Mark 列的单位说反；
- H12：模型把表格第 20 行的 `MappingEncoder` 当成问题里的 P20，或把字段定义当现场值；
- H05：Byte1/2/3 原文已补齐，模型仍把 Byte3 的“重试次数”概括成时间单位。

这些题的共同点：关系完全由原文结构（工作表/行/列/表头、Byte 块、限制/默认/单位短语）确定，
不需要模型自由生成。因此新增两条**服务端确定性拼装**路径，命中时直接返回可核对回答；
不命中则返回 `None`，继续走原模型生成路径。

## 开关

| 环境变量 | 默认 | 行为 |
| --- | --- | --- |
| `RAG_TABLE_ANSWERS` | `0` | xlsx 表格参数题：按行/列/表头直接回答索引、字段说明、Unit/Mark、现场值未知 |
| `RAG_PARAMETER_ANSWERS` | `0` | Byte N 参数题：按原文块直接回答控制、限制、默认值、单位；无单位不补 |

两开关独立；关闭时 `llm.chat`/`stream_chat` 行为与改造前一致。

## 命中与输出

### 表格（`app/table_answers.py`）

- 条件：来源含 `.xlsx` 片段，能解析 `工作表《Sheet》第 N 行：A18=20；...` 与表头行；
  问题点名字段（Name 列匹配）或 `P<数字>`（按 Index 列值定位）；且问索引/字段说明/单位/现场值。
- 输出：工作表、真实行号、字段名、目标行引用 `[n]`；索引取 Index 列值并明确“行号不是索引”；
  Unit 与 Mark 分别给真实单元格值；现场值未知时明确“只有定义、没有实测/读取值”。
- 同名字段多来源：逐份列出，不裁定优先级。
- 非 xlsx/无属性词/字段未命中/表头不可靠：返回 `None`。

### Byte 参数（`app/parameter_answers.py`）

- 条件：问题点名 `Byte N` 且问控制/限制/默认/单位，片段有对应 `Byte N: ...` 块。
- 输出：控制内容、`must be >N` 限制、`default … N` 默认值、原文单位；
  原文没有单位写“未给出计量单位”，重试次数明确“不是时间单位”；
  片段缺失的 Byte 明确“未提供”；每项标注来源编号。
- 不命中：返回 `None`。
