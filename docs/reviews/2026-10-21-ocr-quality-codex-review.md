## O1 / P2：直接按精确 y 坐标排序，打乱同一表格行的列顺序

位置：`scripts/ocr_preprocess.py:392–396`，调用处 `:434`。

独立复现使用提交验收脚本生成的同一张 3×3 表格，只将原图旋转 90° 或 270°。两例均识别出全部 9 个单元格，但输出变成：

```text
周期 / 上限 / 项目
每季度 / 巡检 / 400元
18-27摄氏度 / 温度 / 每班
```

应当分别为 `项目 / 周期 / 上限`、`巡检 / 每季度 / 400元`、`温度 / 每班 / 18-27摄氏度`。这会破坏表头与数值的对应关系，后续检索只能拿到错误顺序的纯文本。

根因已用真实引擎输出隔离：转正后引擎原始顺序正确；表头三个框中心 y 分别为 **139、138、138.5**。按 `(y_center, x_center)` 精确排序把“周期”和“上限”放到“项目”前。并非 OCR 漏字或原图表格不清楚。页面识字均分约 0.9972，不能证明结构正确。

最小方向：复用转正后的正确引擎顺序，或先按文字框高度/垂直重叠识别同一行，再按 x 排列；无法证明结构时保留原输出并提示人工核对。补测同一表格的正向、90°、270°，允许同一行框中心存在轻微偏差。

## O2 / P2：旋转候选为空或分数极低，仍会替换原有高置信文字

位置：`scripts/ocr_preprocess.py:430–434`。

`_mostly_vertical([])` 为 false，空输出因此进入 `horizontal`。随后 `first_vertical or ...` 使原文字框为竖直时无条件选中旋转候选。

独立假引擎控制：首轮识别到 `Pressure must not exceed 0.6 MPa.`，分数 0.98、几何为竖直；三个旋转轮次均返回空。实际结果为 `rotation=90, lines=[]`，原有数字、否定和单位全部丢失。另一个控制中旋转结果分数仅 0.1，也会替换首轮的 0.98 内容。

最小方向：空候选不得参与替换；几何方向不能单独证明文本更可靠。旋转结果不足时保留首轮原文并标记顺序/方向待核对。为“旋转后全空”和“旋转后明显退化”各加一个回归控制。

## O3 / P2：同一页的文字页眉会让扫描正文被整体跳过

位置：`scripts/ocr_preprocess.py:607–610`。这是既有完整性缺口，本次仍存在，并非新排序引入。

独立合成 PDF 的同一页包含 71 个非空白字符的原生页眉，以及一张扫描正文图。原页可直接看到“出差住宿每日上限 400 元”和“温度应保持在 18–27 摄氏度”。工具仅输出页眉，**OCR 调用次数 0**；页面和文件为 `ok`、无 warning、退出码 0，正文事实全部缺失。已核对 PDF 确有图像、渲染预览可见正文，原件 hash 未变。

当前“文字页 + 扫描页”的三页用例不能覆盖“同一页文字 + 扫描正文”。文档中的“混合 PDF 不漏页”也不能证明页内内容完整。

最小方向：增加明确的混合页处理/强制 OCR 入口，并保留原生文字；检测到可疑的大块图像正文时至少提示内容覆盖未核对，避免把仅页眉的输出当完整成功。无需对每个带小 Logo 的正常文字页强制 OCR。补测原生全文、纯扫描、跨页混合、页内混合四种输入。

## O4 / P2：重复运行验收会删除首轮原页与失败输出

位置：`tests/ocr_acceptance_check.py:99–104`，结果覆盖处 `:252–254`。

相同 `--evidence` 再运行时无条件 `shutil.rmtree(work)`，随后 `acceptance.json` 也被覆盖。这与本轮保留首轮答案/原页/失败证据的要求不符。

独立控制只在新建隔离目录放入一份合成的首轮失败文件，再让引擎返回“不可用”。脚本退出 0 / SKIP，但旧 `work/first-failed-output.txt` 已经被删除；甚至没有跑新测试就破坏了上一轮证据，并留下仍指向旧结果的 `acceptance.json`。

最小方向：目录已用时拒绝运行或生成新的唯一批次目录；保持原页、输出和汇总属于同一批次。无需新增通用实验管理框架。

另有两个评价限制必须保留在报告中：

- **180° 仍失败**：原页顺序为“巡检记录 / 上限 / 温度”，实际倒序；页面 `ok`、无 warning、识字均分 0.9995。验收脚本将 `order_ok=false` 放入 `known_limitations`，因此汇总仍 `passed=true` / 退出 0。这只能表示部分用例通过；未获得用户接受该方向缺口前，不应称全部旋转行序验收通过。暂不要求增加第二套方向模型。
- 旧 `_recall` 只检查每个字符是否在输出中出现，忽略顺序和次数。`压力不得超过 0.6 MPa` 对 `压力得超过 6.0 MPa不` 仍得 1.0，倒序段落也得 1.0。不能用该分数证明数字、否定、行列关系正确；应对关键数值、单位、否定和阅读顺序设独立核对项。

原提交真实运行曾出现数组真假判断异常：离线15组通过，但真实38断言中17通过/21失败，7个识别页失败。候选已将 `txts/scores` 的 `or ()` 改为显式 None 判断；独立 NumPy 控制确认旧版失败、候选通过。该问题在本候选中已修复，不列为待修项。运行时环境问题和这次产品失败均保留，未用后续成功覆盖。
