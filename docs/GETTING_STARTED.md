# 使用入门

1. 运行 `setup_windows.cmd`，保存显示的随机 root 初始密码，打开 `http://127.0.0.1:8088` 并登录。
2. 在管理页上传一份无敏感内容的小型测试文档，等待处理完成。扫描 PDF 先做 OCR。
3. 提一个能在原文中直接找到证据的问题，打开引用确认文本、页码和文档是否一致。
4. 再提一个资料里没有答案的问题，检查系统是否说明不足；不要把流畅表达当成正确性。

普通账号只能检索自己有权查看的文档。管理账号负责上传、用户及文档权限；保留这些功能是为了私有访问安全，不意味着可以直接暴露到公网。

问题涉及多个文件时可指定文档范围。相同术语或 CEID 可能在不同文档、场景下具有不同含义：系统应分别引用并提示差异，而不是自行选定“标准答案”。若来源只记录事件标签，答案应明确完整描述缺失。详见 [CEID 规则](ceid-events.md)。

手机需要先连接同一 Tailscale 网络，再访问电脑的私有 HTTPS Serve 地址。主机要保持开机、联网、不休眠，详细设置见 [Windows 指南](WINDOWS.md)。

已有安装更新前先备份；新 clone 不含原有文档、账号和模型。更多见 [运维说明](OPERATIONS.md)。
