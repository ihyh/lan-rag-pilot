# 使用入门

先按 [Windows 指南](WINDOWS.md) 安装并登录。顶部提供四个入口，按角色显示。

1. **资料管理**：上传手册或表格；图片使用“图文资料”填写可核对的说明。扫描件先核对 OCR。等待资料就绪，再设置设备类型、适用范围和访问授权。
2. **问答工作台**：选择全库或明确勾选文档，再提问。设备按钮会按标注选择相关资料；未标注文件不自动归入某型号。已有对话范围固定，需要换范围时新建对话。
3. **查资料**：按关键词直接找索引原文，或查看文档体检。结果定位文件及页码/段落；未命中不等于原件没有相关内容。
4. **用户与权限**：root 创建和管理账号、角色与用户组。文档的可见用户/组在资料管理中设置。

历史对话每页 25 条，点击页码并选择记录可查看旧结果。回答下可评价、纠错或补充问题；有帮助反馈无需审核，问题反馈由 root 在“资料管理 → 审计 → 用户反馈”核对。

使用答案前核对引用原件、版本和设备范围。审核记录不会自动改写原回答、训练模型或更新知识库。纠正源文档后按需重新上传或重处理，并新建问题复测。
