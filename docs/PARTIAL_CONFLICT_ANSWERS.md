## 已修复的行为

| 触发情形 | 原行为 | 候选行为 |
| --- | --- | --- |
| 明确Index，默认值或当前值列重复 | 整答提前澄清，明确索引也丢失 | 保留索引，重复列按原列名/字母/值/来源分别展示，请用户核对 |
| 来源A默认值明确，来源B列有歧义 | B阻断A | A照常列出，B逐列保留，不选唯一标准 |
| 相同测试项有多条动作或前置条件 | 只读第一条来源 | 检查测试项主体及明确表头，逐来源、逐行保留相关记录和真实编号 |
| 首来源是其它测试项 | 仍返回该动作 | 主体不能精确对应时不走该快捷回答 |
| 同时询问动作与等待时间、条件与指令 | 窄快捷分支只答一项 | 不能由该快捷分支闭合的复合问题回到完整来源生成路径，不伪装成完整答复 |
| 同名结构有EERA/EERB两条定义 | 只读第一条 | 对已识别的结构分别展示，未自动取舍 |
| 同一明确操作有两套指令/回复ID | 按文本相关性分数选择一套 | 先按明确操作字面绑定，分别保留不同值，不能拿相关性分数判断定义真假 |

表格请求项逐来源处理；未询问的歧义属性不会额外列出。缺单元格明确说当前检索片段未提供，不借默认/示例/Index替代当前值。只有歧义而没有明确请求项时仍可返回 `table_clarification`，该字段只是工程分派名称。

快捷投影只接管已识别的窄问法和明确结构。相同输出合并引用但不丢来源，不同记录各带引用，并提示核对设备、协议与版本；这不证明不同场景的资料谁对谁错。未知复合问法、损坏或混行坐标回到携带完整来源的生成路径；回退本身不是正确答案的证据。其它多候选语句也不再按分数差自动投影一条。
