# 完整证据关系组装（第一步：跨页/跨块续段，默认关闭）

依据真实问题错误定位：用户实际差评的三条问题，检索都已把当时来源完整送给模型，模型仍在
“把测试步骤当现场病因、把列表代号读错、把定义当现场值”等理解/关系问题上出错；同时人工核对包
显示参数表、步骤、定义在 PDF 页界/切块边界被拆开时，当前检索只给其中一段（例如 RFT-200S
配置命令的 Byte1 在第 6 页、Byte2/3 在第 7 页）。

因此第一个小范围改造不是扩大召回或重切块，而是**在选段之后按原文结构补齐同一文档的续段**，
让模型看到完整的参数/步骤/定义关系。

## 开关与默认

| 环境变量 | 默认 | 行为 |
| --- | --- | --- |
| `RAG_CONTEXT_CONTINUATION` | `0` | 选段后按原文结构附加同文档下一段；默认关闭，需显式开启并做前后对照 |

默认关闭，便于隔离 A/B 与回滚；开启只改变“送给模型的上下文”，不改变召回排序、chunk、向量、
默认 Top-K、引用编号语义或数据库。

## 触发条件（全部来自原文结构，不让模型补造）

对每个已选来源，只在**同时**满足以下条件时附加同文档 `seq + 1` 的一段：

1. 文件是页/段式文档（`.pdf` / `.docx` / `.txt` / `.md`）；xlsx 行语义靠表头，不在此处扩；
2. 存在同文档下一段且内容非空、未被本次结果选中；
3. 满足以下之一：
   - 当前片段最后一条有效行是未完结句（没有句末标点；忽略水印行、括注行）；
   - 下一段前几行出现续写标记（`Byte 2`、`bit4`、`P150`、`步骤`、`第 N`、编号条目、`续`、
     `注：`、`以及/同时/但/若` 等）；
4. 下一段不是新章节开头（`1.2.3` 数字小节、`第X章`、`一、` 等），避免把无关新页带进来。

最多附加 2 段；续段以独立来源附在锚点之后，保留真实 `filename/page/seq/chunk_id`，
`score` 留空、`continuation_of` 记录锚点，不伪造相似度。

## 边界

- 不重切 chunk、不重算向量、不改召回/重排/默认 Top-K；
- 不跨文档补关系（同号不同定义的跨文档保留是下一步）；
- 不做表格/参数的语义推断，只按原文相邻与续写标记附加；
- 关闭开关时行为与改造前完全一致。

## 验证

- 公共离线检查：`python tests/context_continuation_check.py` —— **14 项通过**，
  覆盖未完结尾句、页眉噪声后的 Byte 续写、完整句不扩段、括注行+新章节不扩段、
  xlsx 不扩段、缺 seq/空内容安全、数量上限与去重。
- 真实问题前后对照（私有、不提交仓库）：
  - 12 题人工核对包：H05 必要证据覆盖 1/2 → **2/2**（Byte1 第 6 页 + Byte2/3 第 7 页），
    回答由“仅 Byte1，其余无法确认”变为 Byte1/2/3 的控制、限制、默认值、单位均完整；
  - 25 条真实使用：对当时来源的覆盖无下降，未引入新的必要证据丢失；
  - 收紧“新章节/括注行”规则后，去除了把无关下一页（如操作手册 Tool 小节）附加进来的误扩。
- 开关默认关闭，`tests/run_checks.py` 全量回归保持通过。

## 下一步

1. 表格/参数关系：xlsx 目标行必须同时带上表头、Unit/Mark 单位与脚注；跨页参数续段已覆盖；
2. 同号/同名不同定义：成对保留来源，不替模型裁定优先级；
3. 对“证据完整仍答错”的题，再做“直接回答＋逐项依据＋数字/引用检查”的生成改造；
4. 用同一批真实问题 + 人工包做前后对照后再决定默认开启；重排/召回数量/模型更换留到最后。
