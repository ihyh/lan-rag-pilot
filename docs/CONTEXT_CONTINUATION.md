# 完整证据关系组装（第一步：跨页/跨块续段，默认关闭）

依据真实问题错误定位：用户实际差评的三条问题，检索都已把当时来源完整送给模型，模型仍在
“把测试步骤当现场病因、把列表代号读错、把定义当现场值”等理解/关系问题上出错；同时人工核对包
显示参数表、步骤、定义在 PDF 页界/切块边界被拆开时，当前检索只给其中一段（例如 RFT-200S
配置命令的 Byte1 在第 6 页、Byte2/3 在第 7 页）。

因此第一个小范围改造不是扩大召回或重切块，而是**在选段之后按原文结构补齐同一文档的续段**，
让模型看到完整的参数/步骤/定义关系。复核后已收紧边界（见下）。

## 开关与默认

| 环境变量 | 默认 | 行为 |
| --- | --- | --- |
| `RAG_CONTEXT_CONTINUATION` | `0` | 选段后按原文结构附加同文档下一段；默认关闭，需显式开启并做前后对照 |

默认关闭，便于隔离 A/B 与回滚；开启只改变“送给模型的上下文”，不改变召回排序、chunk、向量、
默认 Top-K 或引用编号语义。新增续段来源没有相似度分数，`chat_sources.score` 允许为 NULL，
历史来源可完整恢复（不再用整数分数伪造）。

## 触发条件（全部来自原文结构，不让模型补造）

对每个已选来源，只在满足以下条件时附加同文档 `seq + 1` 的一段：

1. 文件是页/段式文档（`.pdf` / `.txt` / `.md`）。xlsx 行语义靠表头，不在此处扩；
   **DOCX 不在此处扩**：现有解析先输出全部普通段落、再输出全部表格，`seq` 邻接不等于原文邻接。
2. 存在同文档下一段且内容非空、未被本次结果选中。
3. 满足以下之一：
   - 当前片段最后一条有效行是未完结句（没有句末标点；忽略水印行、括注行）；
   - 下一段前几行出现**明确续写标记**（`Byte 2`、`bit4`、`P150`、`步骤`、`第 N`、`续`、
     `注：`、`以及/同时/但/若` 等）。仅“数字+点/顿号”（`6.`、`2、`）不算续写依据。
4. 新章节处理：
   - 下一段开头就是新章节（`6.`/`6.1`/`第X章`/`一、`/Markdown 标题）→ 不附加；
   - 新章节出现在续文之后（如 `Byte 2`、`Byte 3` 后接 `5.4 Reset command`）→ 只保留新章节
     之前的续文，并记录 `trimmed_at_section`，不把无关新章内容一起带入。

最多附加 2 段；续段以独立来源附在锚点之后，保留真实 `filename/page/seq/chunk_id`，
`score` 留空、`continuation_of` 记录锚点，不伪造相似度。

## 边界

- 不重切 chunk、不重算向量、不改召回/重排/默认 Top-K；
- 不跨文档补关系（同号不同定义的跨文档保留由 `RAG_EVIDENCE_COMPLETION` 负责）；
- 不做表格/参数的语义推断：只按原文相邻与明确续写标记附加，无法确认就不补；
- 关闭开关时行为与改造前完全一致。

## 验证

- 公共离线检查：`python tests/context_continuation_check.py` —— **23 项通过**，
  覆盖未完结尾句、页眉噪声后的 Byte 续写、完整句不扩段、括注行+新章节不扩段、
  顶层/多级新章节不扩、仅数字+顿号不扩、续文后新章裁剪、DOCX 不扩、xlsx 不扩、
  缺 seq/空内容安全、数量上限与去重。
- 持久化契约：`tests/context_evidence_persistence_check.py` —— 只开续段时普通/流式问答
  都完整保存来源，续段来源 `score=NULL`；历史来源可恢复；旧库 `NOT NULL` 迁移可写 NULL；
  保存失败整轮回滚，不留 `status=ok` 的残缺记录。
- 真实问题前后对照（私有、不提交仓库）：
  - 12 题人工核对包：H05 必要证据覆盖 1/2 → **2/2**（Byte1 第 6 页 + Byte2/3 第 7 页）；
    但**答案仍不正确**：两个候选首答仍把 Byte3 的重试次数概括成时间单位。
    “证据补齐”不等于“答案正确”，不能把覆盖提升记作准确率提升。
  - 25 条真实使用：对当时来源的覆盖无下降，未引入新的必要证据丢失；该统计不等于答案正确率。
  - 收紧“新章节/括注行/文档类型”规则后，去除了把无关下一页（如操作手册 Tool 小节）
    和 DOCX 表/段落错序附加进来的误扩。
- 开关默认关闭，`tests/run_checks.py` 全量回归保持通过。
