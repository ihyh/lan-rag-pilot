# 项目进度与发布边界（2026-10-20）

当前主线是 Windows 个人知识库。此代码快照包含通用检索实验工具和独立原文核对预览；**代码发布不等于启用实验、生产部署或业务正确率提升**。

## 已提供

- 通用词法、CPU重排、历史辅助语义检索的独立实验开关，均默认关闭；保留旧基线路径。详见[通用检索实验](GENERIC_RETRIEVAL.md)。
- 分层检索评测工具：分别记录候选召回、必要证据完整性、选段丢失、耗时和身份摘要。检索命中不作为事实正确判断；真实问题、原文和报告留在本机隔离目录。
- [文档证据资格](EVIDENCE_ELIGIBILITY.md)与[来源调用契约](EVIDENCE_REQUEST.md)：绑定数据库原文和来源身份，输出前复查权限/来源；文档记录不能自行升级为现场当前状态或维修适用性。
- [隔离原文交互预览](EVIDENCE_PREVIEW.md)：明确选择用途、授权检索、选择完整片段、稳定引用编号、安全纯文字显示、JSON/缓冲NDJSON一致。独立登录/只读数据库，仅限本机回环诊断，**普通问答页面未接入**。

## 验证到什么程度

原文资格/调用/预览分别有22、38、31项合成契约控制。另完成14项本地真实嵌入与授权检索API控制，以及10项实际浏览器观察。它们验证功能、来源保真和安全边界，**不是业务题集正确率**，也不是对检索相关性、冲突完整召回或原文语义的自动认证。

目前没有人工确认的真实业务验收集；不发布一个没有依据的“总体正确率”。原文预览不是新的生成答案方案。默认生成模型仍是4B设置，当前快照不自动切换模型或重建文档索引。

## 使用与下一步

普通安装/启动和合成smoke说明见[项目首页](../README.md)。新原文契约可单独验证：

```powershell
python tests/evidence_eligibility_check.py
python tests/evidence_request_check.py
python tests/evidence_preview_check.py
```

这些检查不需要私有文档、模型下载或生产服务。独立预览使用方法和限制见对应说明，不要将诊断工具发布到VPN或公网。私有文档、数据库、模型、访问码、原始回答及评测报告均不属于发布源码。

下一步准备未参与当前开发的新诊断问题与对应原文，覆盖跨来源冲突、片段不完整、中文查询、追问和权限范围，分别评估错误结论、误拒绝和实际可用性。通过后再单独决定是否接入正式界面；不靠题目特例或只挑最好回答提高成绩。
