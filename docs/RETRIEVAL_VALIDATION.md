# 检索与答案验证

当前采用精确关键词与向量语义混合召回，结合文件名、文档范围、账号权限和来源约束。相邻编号不是目标编号，标题命中不代表正文证据充分；需检查最终答案实际使用的文本。

CEID 查询优先匹配完整数字 ID，收集相同 ID 的不同事件与场景，不因语义排名或分数阈值抹去冲突。自然语言先找到事件 ID，再补充同 ID 相关定义。原文只含标签时明确描述不足；完整事件不得在普通切块长度处硬截断。参见 [CEID 说明](ceid-events.md)。

## 验证顺序

1. 固定问题、原始文档版本和正确证据，不从当前错误答案反推评分标准。
2. 分别检查提取文本、事件边界、精确召回、来源权限及生成答案。
3. 使用重复 ID、相邻 ID、跨场景、截断、缺证和权限隔离等负例；不能只测试成功示例。
4. 在独立数据目录、非生产端口执行，记录模型与源码版本，保留原答案和失败证据。
5. 区分事实正确、引用正确、覆盖程度与拒答，不因答案更长判为更好；不以小样本通过率代表整个知识库。

公开回归使用合成资料，`python tests/run_checks.py` 和 Windows smoke 可从全新 clone 运行，不依赖本机私人测试集。真实模型质量测试使用 [评测工具](../eval/README.md)，mock 路由测试不证明真实生成准确率。

生产部署、索引重建和生产发题分别授权和记录。重处理旧 CEID 文档前备份数据；不能把新源码已通过合成测试误写成生产索引已修复。
