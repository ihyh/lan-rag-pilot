# 检索与答案验证

开发候选2026-10-25：非rerank选段现支持明确字段/无符号整数关系和有限的缺失原词`-ing`词形，提升仅限同文档已召回候选，保留其它文档槽位、精确技术词和来源身份。追踪区分包含去重/空正文/预算及证据提升。原混合召回和RRF不变，未部署；已见三题仅验证关键原文恢复到提示输入，没有新答案正确率。详见本轮选段验证（未随仓库提供：`reviews/2026-10-25-query-constraint-selection.md`）。

当前采用精确关键词与向量语义混合召回，结合文件名、文档范围、账号权限和来源约束。相邻编号不是目标编号，标题命中不代表正文证据充分；需检查最终答案实际使用的文本。

检索按通用关键词、向量与文档范围处理，不使用专用事件目录或事件问答分支。覆盖程度仍受解析、切块和召回预算影响，需要用原始证据验证，不能假定某一编号的所有定义都已召回。

## 验证顺序

1. 固定问题、原始文档版本和正确证据，不从当前错误答案反推评分标准。
2. 分别检查提取文本、事件边界、精确召回、来源权限及生成答案。
3. 使用重复 ID、相邻 ID、跨场景、截断、缺证和权限隔离等负例；不能只测试成功示例。
4. 在独立数据目录、非生产端口执行，记录模型与源码版本，保留原答案和失败证据。
5. 区分事实正确、引用正确、覆盖程度与拒答，不因答案更长判为更好；不以小样本通过率代表整个知识库。

公开回归使用合成资料，Windows smoke（`tests/smoke_runner.ps1`）可从全新 clone 运行，不依赖本机私人测试集；本仓库未包含 `tests/run_checks.py`。真实模型质量测试使用 评测工具（未随仓库提供：`../eval/README.md`），mock 路由测试不证明真实生成准确率。

生产部署、索引重建和生产发题分别授权和记录。重处理旧文档前备份数据；不能把新源码已通过合成测试误写成生产索引已修复。

## 离线评测范围不能悄悄缩小

`scripts/retrieval_eval.py` 对显式 `scope` 先校验严格正整数ID，再核对当前就绪/启用资料。任一文档缺失、未就绪或已成为历史版本时，在索引与嵌入加载之前中止整轮；JSONL日志记录 `scope_blocked`、题号、原范围和全部不可用ID，不产生该轮评分报告。不能取剩余文档交集后继续计算成绩。

不同格式的空值语义不要直接复制：

| 格式 | 含义 |
| --- | --- |
| 历史会话 `document_ids=[]` | 当时的全库模式；复测前须明确当前冻结范围，不等于已复原历史全库 |
| 离线检索题 `scope=null` 或缺省 | 当前就绪且启用的全部文档 |
| 离线检索题 `scope=[]` | 空范围，不回退全库 |
| 新隔离问答题 `rag-eval-v2` | `scope_mode=selected`，必须有非空且已冻结身份的文档ID |

重复ID沿生产请求的既有语义去重，布尔/字符串/越界ID拒绝。没有生命周期列的历史快照仍按ready兼容，并在报告标记 `legacy_snapshot_without_lifecycle`，不冒充已验证active-only。

若原范围已无法恢复，可以另建**明确标记新范围**的诊断，但不能冒称同条件复测。候选来源命中、HTTP成功、原文存在或页码一致，都不能替代人工整答验收。
