# 来源附注与回答范围

生成指令要求直接回答被问事实和必要步骤，避免额外总评“其它片段都不支持”。没有引用某段，不等于该段没有相关内容；不能以某段的一部分概括全部。

以下说明仍需保留：用户明确询问的来源比较、被问属性的缺项、真实定义差异，以及影响操作的前提、限制和否定条件。缺项判断限于实际片段，不能扩大为整份手册不存在。

此改动仅是共享系统提示词三句约束，同步与流式都使用。不增加正则删附注、语义校验器、模型调用或回答自动批准。`answer_literal_audit.py`仍只诊断字面出现，不能证明否定关系是否成立。

公开六组合成反例（未随仓库提供：`../eval/source_commentary_cases.json`）涵盖未问的来源否定、明确比较、部分缺项、不同设备定义、必要禁止条件和无依据拒答。测试经MockTransport核对12次同步/流式请求及完整来源，坏回答仍原样保存；这些测试不证明模型会遵守提示词。
