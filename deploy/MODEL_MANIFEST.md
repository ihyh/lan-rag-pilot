# 离线交付与模型清单模板

[返回首页](../README.md) · [制包步骤](../docs/OFFLINE_PACKAGE.md) · [选型](../docs/MODELS.md)

这是**空白交付模板**，不是已验收的模型清单。管理员每次发布在受控位置填一份，不在公共仓库保存内部机器信息或资料。旧实验机的模型、地址和耗时不能代表目标服务器。

## 软件来源

| 项目 | 实际值（待填） |
|---|---|
| 发布编号/日期/交付人/接收人 | 待填 |
| 源码完整 commit / 干净导出校验 | 待填 |
| 目标 OS/版本/架构 | 待填 |
| Python/依赖锁及 wheelhouse 摘要 | 待填 |
| Docker/Compose/Ollama/Nginx 版本 | 待填 |
| GPU 型号/驱动/Toolkit（无则注明） | 待填 |
| 最终 RAG/Ollama 镜像 ID/来源 digest | 待填 |
| 外层交付包 SHA-256 与可信签名验证 | 待填 |
| 源码/依赖/模型许可证及再分发审核 | 待填 |

## 模型

| 角色 | 必须记录 |
|---|---|
| 嵌入 | 仓库 ID、完整 revision、目录校验、tokenizer、维度、CPU 后端、离线加载结果 |
| 生成 | Ollama 精确标签、完整 manifest digest、量化、模型包校验、上下文和并发 |
| 切片 | 代码版本、max tokens/overlap；不是另一个需下载的模型 |

同时记录目标 .env 中实际路径/地址的受控副本，密钥不要放进普通清单。标签可变，只有标签不足以证明权重一致。

## 必须实测，未测写“未测”

- 无外网、无历史缓存的干净系统安装是否成功，有无下载尝试。
- st 嵌入维度、实际生成模型 ID、CPU/GPU 分配。
- 硬件/RAM/VRAM、首字/总耗时、并发、上下文、模型冷/热状态。
- 问答集版本、人工命中/引用/拒答/忠实度，不能只写“运行成功”。
- 重启、备份、恢复、新旧引用核验。
- 入口/出口、TLS、账号/文档权限验收与风险签字。
- 回退包/数据位置及保留期限。

现有版本的部门/个人文档隔离缺失，涉及该要求的企业验收项不能填“通过”。只有完整证据满足 [安全门槛](../docs/SECURITY.md)后才放行。
