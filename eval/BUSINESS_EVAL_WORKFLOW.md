# 业务问题评测工作流程

用于整理真实问题、核对依据和保存对照结果。独立未见业务题验收目前按用户要求暂跳过，不计通过。本机调试题与报告不发布，也不作为公开正确率证据。

## 1. 从候选到已核对题

逐题核对原问题、设备型号、协议、版本及资料范围。追问先结合用户上下文写成完整独立问题，同时保留原问题；不能用旧系统答案补造前提。

对照原件及适用范围填写期望回答和依据位置。涉及表格、图片或 OCR 时，检查原件是否与入库片段一致。指出资料不足或相互冲突的题也需人工确认哪些资料已查过、应如何回答；未查到不等于全库不存在。资料有误、来源缺失、现场状态未知或答案仍有争议的题保持待核对，不标成金标。

只有问题、期望回答、资料范围及来源均经人工确认，才能另存为相应工具支持的执行格式。反馈中的“有帮助”、旧答案、引用编号和自动检查均不能代替人工核验。有关来源和原始范围的审核约束见 [反馈审核说明](../docs/FEEDBACK_REVIEW.md)。

## 2. 分开回归题与独立留出题

- **回归题**：用于诊断和调整的旧问题，例如已知差评、此前调试过的问题及其同一事实的变体。记录其已被使用的事实，不能宣称是独立验收题。
- **留出题**：选择尚未用于调试的真实问题，由业务人员独立核对答案和原件；同一事实或同一指令的变体放在同一组，不跨两个集合。留出题不参与规则和参数调整；一旦用于调试，转为回归题，另找留出题。

数量不足时保留已核对题和待核对候选，标明留出集未就绪，不用合成题或未经核验题凑数。按型号、指令/状态码、步骤、图文与缺证/冲突等场景逐步补齐。

## 3. 固定基线和隔离执行

固定本轮代码版本、题集及其摘要、资料副本及版本、索引、设备范围、模型和参数；同时记录时间和账号权限。不同轮对比只改待验证的因素，资料、题目或范围改变时注明变化，不冒充同条件。

1. 使用独立数据库、上传目录及非生产端口。真实问答会生成对话和审计记录；不要在正式服务发评测题、重建索引或修改正式资料。副本需要按测试账号当前权限验证可访问范围。
2. 来源和期望经过人工确认后，再按 [评测集说明](README.md) 准备 `eval_runner.py` 的 JSONL，先执行 `--validate-only`；该格式默认至少 30 题，可显式调整 `--min-cases` 做小规模诊断，但不代表达到验收数量。它会通过 HTTP 真正提问；运行前确认目标是隔离服务。
3. 若需要冻结明确的选中文档范围、文件与索引身份，可使用 `scripts/isolated_replay.py --cases <已确认题集>` 先做格式校验，再在独立服务以 `--execute --isolated --base-url <非8088的本机地址> --out <新报告>` 运行。它只接受明确选中文档的 `rag-eval-v2`，不等于历史全库或原始多轮上下文复现；格式通过也不等于原件和答案已人工核对。
4. 需要定位检索环节时，按 `scripts/retrieval_eval.py` 要求准备含 `development` / `acceptance`、事实组和人工核对证据切片的 JSON。以 `--validate-only` 检查格式，随后在固定资料副本上分别记录候选召回和最终证据覆盖。该工具只读数据库、不生成答案；`scope=null` 表示当前启用全库，`scope=[]` 表示空范围，不能混同历史会话中的空列表。范围缺失或变化应停止并核对。

以上工具的字段与调用约束以各脚本及 [检索验证说明](../docs/RETRIEVAL_VALIDATION.md) 为准；不要把候选强行改成已核对状态来绕过校验。

## 4. 分层记录与保留首次结果

每题保留原始回答、实际来源及位置、执行状态、耗时和报告；失败、超时、未执行及重试都保留，重试单独记录，不能覆盖首次结果。私有报告存放在受控目录。

| 层次 | 记录内容和常见失败 |
| --- | --- |
| 原件与解析 | 原件是否正确、版本是否适用；OCR 错字、缺表格、跨页步骤不完整 |
| 召回与选段 | 关键依据是否进入候选、最终是否送入回答；未召回、选段丢失或范围不匹配 |
| 回答和引用 | 事实是否正确、每项依据是否支持、是否漏条件或无依据扩写、是否自相矛盾 |
| 缺证和执行 | 应说明无法确认却给出确定结论、明明可答却拒答；另记网络/模型/权限错误及耗时 |

按 [答案验收判据](../docs/_history/ANSWER_ACCEPTANCE.md) 人工逐条标注；执行成功、关键词命中、找到文件和引用编号有效都不等于整答正确。尚未人工复核的标“待核对”，不写“通过”；未运行的标“未执行”，不计入成功。小批次只报告本批观察与限制，不推断整个知识库的准确率。
